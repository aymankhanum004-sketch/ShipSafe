
# ShipSafe — Onboard IT Operations Desk

## About the Project

ShipSafe is a beginner-friendly IT support and cybersecurity
dashboard inspired by the types of tasks an IT support team
may perform onboard a cruise ship.

This project uses fictional data for educational purposes.

## Project Goals

- Practise basic IT support workflows.
- Learn to track IT issues and their resolution.
- Maintain a simple equipment inventory.
- Record and review simulated security incidents.
- Develop practical web development skills.

## Technologies Used

- HTML — page structure
- CSS — design and layout
- JavaScript — interactive features
- Browser localStorage — saving practice records

## Features

### IT Help Desk
Create tickets, assign a category and priority, and mark
issues as resolved.

### Equipment Inventory
Record equipment names, types, locations and conditions.

### Security Incident Log
Record simulated security events, assign severity levels
and mark incidents as reviewed.

## How to Run

1. Download or copy the ShipSafe project folder.
2. Open index.html in a web browser.
3. Create practice tickets, equipment records and incidents.

No server or database is required for this version.

## Limitations

- Data is stored locally in the browser.
- Data is not shared between users or computers.
- This is not a production IT service management system.
- It does not connect to real shipboard networks.
- It does not perform actual security scans.
- Browser storage is not a secure backup system.
